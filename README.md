# Modeling

Репозиторий содержит материалы по двум расчетным работам по дисциплине
«Цифровое моделирование». Обе работы посвящены стационарной задаче
теплопроводности в плоской области: моделируется температурное поле платы с
процессором и подбираются допустимые положения микросхемы, для которой
температура должна оставаться в заданном диапазоне.

## Работа 1: теплопроводность в области `(E1 - R1) + P1`

### Цель

Построить расчетную модель стационарной теплопроводности для платы из
гетинакса, разместить процессор с температурой 40 °C и определить два
положения микросхемы размером 1 x 1 см, в которых температура остается в
диапазоне от -10 до 30 °C при двух внешних режимах: -20 °C и 20 °C.

### Решение

Расчет основан на результатах моделирования температурного поля для двух
температурных режимов. Далее выполнены постобработка сетки, интерполяция
температурного поля и перебор допустимых положений микросхемы. Для каждого
положения проверяется, что микросхема полностью лежит внутри области, не
пересекает процессор и удовлетворяет температурным ограничениям в обоих
режимах.

Основные параметры:

| Параметр | Значение |
| --- | --- |
| Материал | гетинакс |
| Коэффициент теплопроводности | 0.214961 Вт/(м·К) |
| Радиус области | 5 см |
| Размер процессора | 1.5 x 1.0 см |
| Температура процессора | 40 °C |
| Размер микросхемы | 1.0 x 1.0 см |
| Допустимая температура микросхемы | от -10 до 30 °C |

Найдено 2354 допустимых положения. Из них выбраны два разнесенных варианта:

| Вариант | Координаты микросхемы, см | Режим -20 °C, min/max/avg | Режим 20 °C, min/max/avg |
| --- | --- | --- | --- |
| 1 | x: 2.35..3.35, y: 0.50..1.50 | -10.00 / 2.48 / -4.12 | 23.33 / 27.49 / 25.29 |
| 2 | x: -1.25..-0.25, y: -3.70..-2.70 | -9.98 / 0.77 / -4.10 | 23.34 / 26.92 / 25.30 |

### Вывод

Модель показала, что даже при нагреве от процессора можно подобрать несколько
безопасных зон для размещения микросхемы. Оба выбранных положения сохраняют
температуру в допустимом диапазоне при холодном и теплом внешнем воздействии;
при этом второй вариант дает чуть меньший разброс температур.

## Работа 2: теплопроводность, вариант 30

### Цель

Решить аналогичную задачу для области варианта 30: построить конечноэлементную
модель, рассчитать температурные поля при внешних температурах -20 °C и 20 °C,
а затем подобрать два допустимых положения микросхемы размером 1 x 1 см.

### Решение

Для варианта 30 построена геометрия области по схеме задания: нижняя
полуокружность с верхними прямолинейными участками и внутренним уступом.
Теплоизолированным принят участок №1. Далее сформирована конечноэлементная
сетка и решена стационарная задача теплопроводности с заданными граничными
условиями. После получения температурного поля выполнена интерполяция, а
положения микросхемы перебраны по сетке с проверкой геометрических и
температурных ограничений.

Основные параметры:

| Параметр | Значение |
| --- | --- |
| Вариант | 30 |
| Материал | гетинакс |
| Коэффициент теплопроводности | 0.214961 Вт/(м·К) |
| Радиус области | 6 см |
| Теплоизолированный участок | №1 |
| Размер процессора | 1.0 x 1.5 см |
| Температура процессора | 40 °C |
| Размер микросхемы | 1.0 x 1.0 см |
| Допустимая температура микросхемы | от -10 до 30 °C |

Найдено 443 допустимых положения. Для отчета выбраны два варианта:

| Вариант | Координаты микросхемы, см | Режим -20 °C, min/max/avg | Режим 20 °C, min/max/avg |
| --- | --- | --- | --- |
| 1 | x: -4.90..-3.90, y: -3.10..-2.10 | -9.82 / -2.83 / -6.47 | 23.39 / 25.72 / 24.51 |
| 2 | x: 2.10..3.10, y: -2.90..-1.90 | -9.93 / 2.57 / -4.25 | 23.36 / 27.52 / 25.25 |

### Вывод

Для области варианта 30 допустимые зоны размещения микросхемы найдены при
теплоизоляции участка №1. Первый вариант является более равномерным по
температуре и имеет меньшую среднюю температуру при внешнем режиме 20 °C,
поэтому он выбран как предпочтительный.

  положений микросхемы.

## Краткий итог

Обе работы демонстрируют полный цикл численного моделирования: постановка
задачи, построение геометрии, расчет температурного поля, анализ ограничений и
выбор инженерно допустимых положений элемента на плате.
